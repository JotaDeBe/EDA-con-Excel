Proyecto EDA con Excel
Este proyecto realiza un análisis exploratorio de los envíos en un ecommerce.El objetivo es identificar patrones para mejorar los tiempos de entrega.
En cuanto a las conclusiones,no he podido identificar patrones que expliquen la demora en las entregas,ya que los datos son similares en cada aspecto estudiado(modo de envío,bloque de almacén o importancia del producto).
